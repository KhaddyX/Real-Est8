## Overview

**Real Est8** is a single-page marketing website for a real estate agent. It highlights:
- Property listings with images, prices, and key details
- Agent credentials and trust signals ($50M+ sales, 200+ clients, etc.)
- Buying and selling services
- Neighborhood guides
- Client testimonials
- A lead-capture modal for home valuation requests

The design is fully responsive, accessible, and optimized for performance with lazy-loaded images and semantic HTML.

---

## Features

### 🏠 Hero Section
- Full-width hero with background image
- Primary CTA: "Get Your Free Home Valuation" (opens modal)
- Secondary CTA: "Search Homes" (links to listings page)

### 📊 Trust Indicators
- Four stat cards: Sales volume, happy clients, years experience, top percent ranking
- SVG icons for visual appeal

### 🏘️ Featured Listings
- Grid of property cards with:
  - Image (lazy-loaded)
  - Price, address, beds/baths/sqft
  - Badges ("New", "Price Reduced")
- "See All Listings" button

### 🛠️ Services Split
- Two-column layout: Buyers / Sellers
- Benefit lists and action buttons

### 📍 Neighborhoods
- Three neighborhood cards with images and descriptions
- "View All Neighborhoods" link

### 💬 Testimonials
- Three client testimonials with author photos and details

### 👤 About Preview
- Agent photo + bio
- "Get to Know Me" link

### 🎯 Final CTA
- "Ready to Make Your Move?" section with contact buttons

### 📬 Lead Capture Modal
- Home valuation form with fields: Name, Email, Phone, Address
- Form validation and submit handler

### 📱 Responsive Navigation
- Mobile hamburger menu toggle
- Header phone number for quick calls

### 🦶 Footer
- Agent info, quick links, social media icons
- Legal disclaimer and Equal Housing Opportunity / MLS logos

# 🏡 Real Est8

A modern and responsive real estate landing page built with HTML, CSS, and JavaScript. It helps real estate agents showcase properties, build trust with potential clients, and generate leads.

![Real Est8 Preview](assets/preview.png)

## ✨ Features

- Responsive design
- Hero section with CTA
- Featured property listings
- About the agent section
- Client testimonials
- Home valuation modal
- Smooth scrolling animations
- Mobile-friendly navigation

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Live Demo

https://khaddyx.github.io/Real-Est8/

## 📂 Installation

```bash
git clone https://github.com/KhaddyX/Real-Est8.git
cd Real-Est8
```

Then open `index.html` in your browser.
